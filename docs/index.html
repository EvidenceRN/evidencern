How it works

From a clinical question to a cited answer

Each search runs the same four steps, and every step is visible to the person asking.

1

Interprets the question

Converts plain language into a PubMed search and shows the exact query it ran, the filters applied, and the search date.

2

Finds and ranks evidence

Retrieves a wide pool of studies, removes retracted records, and ranks the rest by level of evidence, with systematic reviews and guidelines first.

3

Writes a cited answer

Produces a bottom line, a summary of the evidence, and practice implications framed for a generalist RN scope, stated under every answer. Every claim carries a numbered citation.

4

Checks its own work

Flags citation numbers outside the source list and sentences without a citation, so the reader knows where to verify.

Built to be inspected

Transparent by design

Nurses deserve to see how an evidence tool reaches its answers. These features exist so every answer is open to examination.

🔎

Visible search strategy

A panel under every answer shows the question as interpreted, the database searched, the filters, the exact query, and how many records matched.

🏷️

Evidence labels

Each source carries a level-of-evidence label from the Melnyk and Fineout-Overholt hierarchy, inferred from its PubMed publication type.

🚫

Retraction screening

Retracted publications and retraction notices are excluded before ranking. Expressions of concern, errata, and updates are flagged on the source.

📖

Deep read

Pulls open-access full text from PubMed Central for the top Level I sources, reads the results and discussion sections first, revises the answer, and lists what the full text added.

💬

Follow-up questions

Follow-ups draw on the same sources and keep the same citation numbers, so the thread stays traceable.

🛡️

Safety prompts

An urgent-situation banner, a stated scope assumption, and a notice that no institutional policy is connected appear on every relevant answer.

Why open source

Open to examine, test, and improve

EvidenceRN uses public literature, a visible search strategy, labeled evidence levels, retraction screening, and a citation check on every answer. Releasing the code under Apache 2.0 lets the nursing profession examine those choices, test them against real questions from practice, and improve them.

The full application is one readable HTML file and a small server. Anyone with basic technical skills runs it on a laptop in a few minutes.

EvidenceRN is a project of AI + Nurse Academy, which offers nurse-led AI education for nurses and other clinicians.

Scope and limits

  • EvidenceRN is a prototype for education, exploration, and demonstration. It has not been validated.
  • It searches PubMed only. CINAHL, JBI, Cochrane full text, and local policy are on the roadmap.
  • Evidence labels reflect study design. No risk-of-bias or GRADE assessment is performed.
  • Answers draw on abstracts unless full text is available through PubMed Central.
  • Answers assume a generalist RN scope. Your state nurse practice act, your setting, and your employer's policies determine what applies to you.
  • It is not clinical decision support and does not replace institutional policy, protocols, or provider orders.

Run it yourself

Up and running in minutes

EvidenceRN runs on any Mac, Windows, or Linux computer with Node.js 18 or newer. Search works with no account. The written answers use an Anthropic API key, billed to your own account at a few cents per question.

Full setup instructions on GitHub

# download the project
git clone https://github.com/EvidenceRN/evidencern.git
cd evidencern

# add your API key to a private settings file
cp .env.example .env

# start the app, then open http://localhost:3000
node server.js
